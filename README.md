# Снежный север

Небольшая одиночная текстовая RPG на стандартном C++. Игрок исследует суровый северный край, где история героя и его решения определяют дальнейший путь.

## Сборка и запуск

Нужны компилятор C++17 и CMake 3.16 или новее.

```sh
cmake -S . -B build
cmake --build build
./build/game
```

В меню выбери `1`, чтобы начать, `2`, чтобы посмотреть характеристики, или `3`, чтобы выйти.

## О проекте

Игра создаётся небольшими законченными этапами. Сюжет и игровые правила находятся в разработке; подробности будут добавляться вместе с новыми возможностями.
