# Снежный север

Небольшая одиночная текстовая RPG на стандартном C++. Игрок исследует суровый северный край, где история героя и его решения определяют дальнейший путь.

## Сборка и запуск

Нужны компилятор C++17 и CMake 3.16 или новее.

```sh
cmake -S . -B build
cmake --build build
./build/game
```

В главном меню выбери `1`, чтобы начать, или `2`, чтобы выйти. Перед началом игры распредели три свободных очка между Силой и Стужей.
Во время сцены выбери `0`, чтобы посмотреть характеристики и инвентарь; Enter вернёт к текущему выбору.
В инвентаре можно сохранить или загрузить игру. При запуске новой игры загрузка также доступна на экране создания героя. Сохранение хранится в локальном `savegame.txt`.

Тексты сцен лежат отдельно в `data/scenes/`: каждому внутреннему ID сцены соответствует файл `<ID>.txt`. Запускай игру из корневой папки проекта, чтобы она могла найти эти файлы.

## О проекте

Игра создаётся небольшими законченными этапами. Сюжет и игровые правила находятся в разработке; подробности будут добавляться вместе с новыми возможностями.
